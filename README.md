# Smart-Spend

• Built a privacy-first credit card analytics dashboard using Claude AI and Node.js that analyzes spending trends, categorizes
transactions, and parses financial statements entirely in-browser, ensuring zero backend data exposure.

• Reduces financial waste through clear insights and automates analysis in ~2 minutes versus ~2 hours manually, resulting in
significant time savings.

## Quick Start

### Prerequisites
- [Node.js](https://nodejs.org/) v14 or higher
- npm (comes with Node.js)

### Run locally

```bash
# 1. Clone this repo
git clone https://github.com/saee-gore/Smart-Spend-Dashboard.git
cd smart-spend-dashboard

# 2. Install dependencies
npm install

# 3. Start the server
npm start
```
